# 成果 Demo 腳本

> 依序操作即可展示本系統全部核心功能。所有「示範輸入」都經過實測會產生明顯結果。

## 0. 前置啟動

```powershell
# 終端機 A：後端
cd backend
.\run_server.ps1

# 終端機 B：前端
cd frontend
flutter run -d chrome
```

* 後端啟動約 2 秒（會暖機載入路網與多模態路網）。
* 第一次查詢約 0.4~1.5 秒。
* LLM 功能需 `backend/.env` 已填 DeepSeek 金鑰（未填則自動用規則式，仍可展示）。

---

## 1. 走路導航 + 無障礙路線（階梯／陡坡避讓）

**操作**：主畫面 → 用右上方「**設定起點 / 設定終點**」或 🔍 搜尋設定兩點 → 按「規劃路線」。

**示範 A（避開階梯，效果明顯）**

| 起點 | 終點 | 預設 | 開啟「無障礙路線」後 |
|---|---|---|---|
| 大賽車博物館 `22.194553, 113.552713` | 白鴿巢前地 `22.199427, 113.539463` | 1867m，經 7 段階梯 | 2113m，**0 階梯** |
| 黑沙海灘 `22.121270, 113.570990` | 石排灣濕地 `22.126629, 113.561941` | 2514m，7 段階梯 | 5304m，0 階梯 |

**示範 B（避開陡坡）**

| 起點 | 終點 | 預設最大坡度 | 開啟後 |
|---|---|---|---|
| 南灣．雅文湖畔 `22.189503, 113.538846` | 媽閣山 `22.183863, 113.532405` | 36% | **11%** |
| 安德魯餅店 `22.153429, 113.557130` | 觀音岩 `22.164345, 113.555997` | 33% | **10%** |

**講解重點**：打開「無障礙路線（避開階梯與陡坡）」開關後再按規劃，路線會改變；地圖上藍色為步行路線。

## 2. 走 + 公車多模態（真實線形、轉乘、上下車站）

**操作**：打開「**大眾運輸（走 + 公車）**」開關 → 規劃。

| 起點 | 終點 | 結果 |
|---|---|---|
| 關閘 `22.215939, 113.549205` | 澳門旅遊塔 `22.17960, 113.53644` | 步行 → **18 路（12 站）** → 步行 |
| 關閘 | 路環市區 `22.11330, 113.55330` | **30X → 轉乘 → 21A**（需換車才到得了） |

**講解重點**：
* 公車路線**沿實際道路**（紫色線），並標示每一站（紫色圓點）。
* 面板逐步列出「**在『X 站』上車 → 在『Y 站』下車**」，需要換車時標示「轉乘」。
* 點「出發時間」可切到 **02:00** 展示**通宵線**：白天走一般路線，半夜自動改排 **N1A + N3**（N 系列只在 00:00–06:00 行駛）。

## 3. 智慧行程規劃（多景點排序 TTDP）

**操作**：右上角 ✨ → 「智慧行程規劃」→ 設定出發時間／時數／類別 → 「產生行程」。

**講解重點**：
* 系統在時間預算與營業時間內，自動決定「**去哪些景點、什麼順序**」。
* 地圖以**編號標記** 1、2、3… 顯示順序，並串接路線。
* 可設「必訪景點」、限制「美食站數」；勾「無障礙路線」會套用避階梯/陡坡。

---

## 4. 自然語言 AI 規劃（DeepSeek）

**操作**：✨ → 行程規劃頁最上方輸入一句話 → 按「**AI 規劃**」。

**示範輸入（實測過）**：
* `我想看歷史地質路線但不想走太累，6小時`
* `帶嬰兒車輕鬆逛，想食嘢同睇博物館`
* `由大三巴出發，影日落，二人同行，不想行樓梯`

**講解重點**：
* 系統會顯示「**已理解（LLM（deepseek-chat））：…**」摘要，並自動套用類別、時數、無障礙設定。
* 幾秒內就把口語需求（含粵語「食嘢」「行樓梯」）轉成可執行的行程。
* 若未設定金鑰，會顯示「規則式」並改用關鍵詞解析（仍可 demo）。

---

## 5. 儲存行程 / 我的行程

**操作**：產生行程後按「**儲存行程**」命名 → 右上角 🔖「我的行程」可載入（會還原當時設定）或刪除。

---

## 6. 景點搜尋 / 我的位置

* 🔍 **搜尋景點**：輸入關鍵字（如「大三巴」「官也街」），可一鍵設為**起點或終點**。
* **我的位置**：面板上「定位為起點 / 定位為終點」（需允許定位權限）。

---

## 7. 介面收合（示範順手）

* 下方介面的 **▼** 向下收起面板；上方 AppBar 的 **▲** 向上收起；收起後出現方向鈕可還原。
* 讓地圖全螢幕呈現，避免遮擋。
