適應型智慧旅遊導航與路徑調配系統 — 網頁版使用說明
====================================================

這個資料夾是「網頁版」：後端會同時提供 API 與網頁介面，
用瀏覽器打開即可使用，不需要安裝 App。

一、啟動
  1. 確認已安裝 Python 3.11 或以上（Windows 安裝時請勾選 Add python.exe to PATH）。
  2. 雙擊 start-web.bat（Windows），或執行 ./start-web.sh（Linux / macOS）。
  3. 首次啟動會自動建立 Python 環境並安裝套件，需要網路，約數分鐘。
  4. 後端暖機約 30–40 秒；就緒後會自動開啟瀏覽器：
       http://127.0.0.1:8000/

二、手機／其他電腦使用
  1. 與執行後端的電腦連同一個 Wi-Fi。
  2. 在瀏覽器輸入：http://<電腦區網IP>:8000/
     例如 http://10.1.17.228:8000/
  3. 若 Windows 防火牆詢問，請允許「私人網路」的 8000 埠。

三、常見問題
  * 瀏覽器顯示無法連線：確認後端視窗仍在執行、IP 正確、同一 Wi-Fi、防火牆已開放 8000。
  * 地圖空白：需要網路載入 OpenStreetMap 圖磚。
  * 「我的位置」在部分瀏覽器需要 HTTPS 或 localhost 才能使用。
  * AI 規劃需要 backend/.env 設定 LLM 金鑰；未設定時會自動使用規則式解析。

四、備註
  * 網頁版與 API 同源（同一個 8000 埠），因此沒有 CORS 問題。
  * 資料來源：OpenStreetMap（ODbL）、澳門 DSAT（data.gov.mo）、SRTM 30m。
